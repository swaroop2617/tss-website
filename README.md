# TSS Website

This is a basic multi-page website project built using HTML and CSS. I created this to practice designing different web pages and organizing them properly.

## Live Demo  
https://swaroop2617.github.io/tss-website  

## Features

- Multiple pages like events, members, gallery, etc  
- Simple navigation between pages  
- Basic styling using CSS  
- Images used in different sections  

## Tech Used

- HTML  
- CSS  

## Project Structure

```
tss-website/
│── index.html
│── style.css
│── images/
│── events.html
│── achievements.html
│── members.html
│── gallery.html
│── contact.html
│── and more files...
```

## How it works

Each page is written separately in HTML and styled using CSS files. All pages are connected using links so you can navigate through the website easily.

## How to run

1. Download or clone the repo  
2. Open the folder  
3. Open `index.html` in your browser
